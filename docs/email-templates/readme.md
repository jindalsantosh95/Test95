# CRM email template contracts

This folder records EAPI-owned trigger, recipient, merge-field, and copy contracts for templates rendered by the CRM email platform. It does not contain deployable HTML because CRM/Adobe Campaign owns template rendering and provisioning.

| Template | Producer | Purpose |
| --- | --- | --- |
| [`FCGOL-YF-01`](young-flyer-enrolment-confirmation.md) | Loyalty Member Management | Confirms to a parent or guardian that a managed Young Flyer account was created and linked. |

A template contract is not ready for production until the CRM team has provisioned its identifier in every target environment and the matching deployment setting has been verified.
