# Harness Capabilities Matrix

This matrix summarizes what the repository harness can do today. Use it as the quick-read capability map, then follow the linked docs or scripts for operating details.

Policy terms:

- `required`: expected to block locally, in CI, or both for the owning scope.
- `advisory`: useful signal that does not block unless a scope promotes it.
- `guidance`: feedforward help that shapes agent or contributor behavior.
